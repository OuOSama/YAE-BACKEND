# 🐶 Bruno: The Fast & Git-Friendly API Client

### ✨ What is Bruno?
A **Local-first**, open-source API client that saves your collections as plain files directly in your project folder. No cloud bloat, just speed.

---

### 🛠️ Key Capabilities
* **Local Filesystem:** Saves everything as `.bru` files.
* **Git-Ready:** Version control your APIs effortlessly.
* **Multi-Protocol:** REST, GraphQL, WebSocket, and gRPC.
* **JS Scripting:** Powerful automation & testing via JavaScript.
* **Privacy:** 100% offline; no forced sync or data mining.

---

### 🚀 Why Bruno?
* **Lightweight:** Fast startup & low RAM usage—perfect for multitasking.
* **IDE Friendly:** Edit requests directly in VS Code.
* **Secure:** Your secrets stay in your repo, not on someone else's server.
* **Open Source:** Community-driven and completely transparent.
